# 🕵️ Image Forgery Detection (Python + Computer Vision)

Detects whether an image was tampered with — and roughly **where** — using two complementary classical techniques:

| Forgery type | Method |
|---|---|
| **Splicing** (region pasted from another photo) | **Error Level Analysis (ELA)** + content-normalised features → Random Forest |
| **Copy-move** (region duplicated inside the same photo) | **SIFT keypoint self-matching + RANSAC** (handles rotation/scaling) |

![Examples](images/01_examples_ela.png)

> ⚠️ **Synthetic benchmark.** I generate the forgeries myself from 6 natural photos (bundled with scikit-image/scikit-learn) so ground-truth masks are exact. Every image follows the same recipe (JPEG q=70 → tamper → save q=95). Results demonstrate the methods on a controlled benchmark and are **not** a claim about real-world forensic accuracy.

## 🧰 Tools
Python · OpenCV · scikit-learn · NumPy · pandas · SciPy · Matplotlib · Seaborn

## 🔬 Pipeline
1. **Dataset generation** (`src/make_dataset.py`): 1,200 images (256×256) — 600 authentic, 300 splicing, 300 copy-move; feathered blending, random shapes, rotation ±15° and scale 0.9–1.1× for copy-move.
2. **ELA features**: 12 global statistics + 7 content-normalised features (ELA relative to local level, noise-residual statistics, ELA-texture correlation).
3. **Random Forest** with **Leave-One-Source-Out** cross-validation: trained on 5 photos, tested on the unseen 6th (a random split would leak, since crops of the same photo look alike).
4. **Copy-move detector** (no training): SIFT matches an image against itself; distant matches that agree on one similarity transform (RANSAC) → forgery.
5. **Combined decision** and **localisation** (IoU against ground-truth masks).

## 📊 Results
**ELA + Random Forest** (leave-one-source-out, out-of-fold predictions)

| Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|
| 0.753 | 0.711 | 0.855 | 0.776 | 0.813 |

**Combined detector** (ELA+RF **or** ≥ 4 consistent copy-move matches)

| Accuracy | Precision | Recall | F1 |
|---|---|---|---|
| 0.762 | 0.711 | 0.882 | 0.787 |

| Correctly classified | ELA + RF | Combined |
|---|---|---|
| Authentic | 65.2% | 64.2% |
| Splicing | 92.7% | 93.0% |
| Copy-move | 78.3% | 83.3% |

- **Copy-move detector alone:** catches 45.7% of copy-moves while wrongly flagging only 1.0% of authentic images (ratio 0.6, ≥ 4 inliers).
- **Localisation (splicing):** median IoU 0.23, mean 0.30; 41% of images IoU > 0.3, 20% IoU > 0.5 — ELA gives a rough hint of the region, not a clean segmentation.
- Accuracy varies by held-out photo (57%–87%), showing how content-dependent ELA is.

### What worked, what didn't
- ✅ Splicing is detected well (≈93%) and the copy-move detector is very precise.
- ✅ Adding content-normalised features raised accuracy from 66% → 75% and AUC from 0.72 → 0.81 (one experiment, run after seeing the first result).
- ❌ **Authentic images are falsely flagged ~35% of the time** — ELA statistics vary a lot between photos, so a real system would need a threshold calibrated for an acceptable false-positive rate.
- ❌ Copy-move recall is moderate: small, low-texture patches give few keypoints.

## ⚠️ Limitations
- Synthetic data with one compression recipe; real-world forgeries (resizing, noise, repeated re-saves, unknown history) degrade ELA considerably.
- Only 6 source photos; generalisation to other scenes is unproven.
- Copy-move parameters were chosen on the evaluated images (no training, but recall is slightly optimistic).
- Next step: deep-learning detectors (noise-print / CNN) on a real benchmark such as CASIA v2.
